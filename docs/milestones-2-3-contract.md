# Milestones 2–3 implementation contract

The browser editor, immutable world library, local render queue, World Labs experiment workflow and experimental Gaussian-to-mesh conversion are implemented. The final comparison uses the authored baseline, an official World Labs HQ textured visual GLB, and a GLB reconstructed locally from the **same world's Gaussian SPZ**. Both generated alternatives end as meshes; native Gaussian preview/plates remain diagnostic paths. Generated-world fidelity, calibrated alignment, human approval and usability gates remain unmeasured until the actual results are reviewed. Synthetic QA fixtures are labeled accordingly.

Coordinate contract and exact sampled poses remain unchanged. Browser uses Three.js canonical Y-up; Blender uses (x,-z,y). Vertical camera gate is 36 mm, so browser vertical FOV is 2*atan(18/focalLengthMm). Shared Python evaluation controls the exact product, sampled cameras and confirmed actions across conditions. The five probes are contact, lateral camera movement, foreground occlusion, glossy material and solid glass: fifteen unreviewed scene documents, not approved final renders. Common world lineage does not establish common metric scale; review axes, scale and ground alignment before drawing quality conclusions.

## World asset contract

Keep existing `environment` fields worldColor/plinth/provenance/revisionId. `kind` accepts `authored`, `mesh` and diagnostic `splat`. Mesh and splat entries require:

```json
{"asset":{"path":"assets/<sha256>.glb","sha256":"<64 lowercase hex>","format":"glb","sourceUp":"Y","scaleToMeters":1,"translationM":[0,0,0],"rotationXyzw":[0,0,0,1]},"reviewStatus":"unreviewed","displayName":"World name"}
```

For splat, format is `spz` or `ply`; path suffix matches. Import transform: first convert sourceUp Y/Z to canonical Y, apply uniform scaleToMeters, rotationXyzw then translationM. GLB is Y-up by specification. Splat sourceUp must be explicitly supplied/reviewed. No collision mesh accepted as a visual mesh. Provenance is required; source hashes pin immutable files. For synthetic assets add `fixture:true` and accurate provenance.

The asset and job interfaces are implemented in `film/worlds.py`, `film/scene.py` and `film/jobs.py`, with contract checks in `tests/test_worlds.py`:

- `import_world(source_path, library_root, *, name, provenance, source_up='Y', scale_to_meters=1, fixture=False, translation_m=None, rotation_xyzw=None)` -> library entry `{id,name,environment}`. library_root/assets holds immutable hash-named copies; library_root/worlds stores immutable entry JSON. Determine GLB/SPZ/PLY from suffix; validate self-contained GLB 2 (no external URIs/scripts), Gaussian headers/data and a 128 MiB input bound. Library entry environment includes neutral worldColor/plinth baseline.
- `list_worlds(library_root)` -> entries.
- `bundle_assets(scene, source_dir, destination_dir)` -> verify scene asset hash, copy to destination_dir/assets preserving relative asset.path; no scene mutation. Returns list of records if useful. Resolve relative paths only; reject parent traversal/absolute/network paths and paths outside source root.
- create_job calls bundle_assets before writing snapshots, `_verify_snapshots` rechecks bundled asset content. Renderer reads asset paths relative to samples JSON parent. No active worker races with renderer source updates; legacy output directories are historical.
- `evaluate` placement follows `restsOn` plinth translation change. World movement does not move the exact near-field ledge implicitly; placement is deterministic, without inferred physics. Optional material `transmission` and `ior` have validated ranges and support the explicit glass probe. The probe is a solid primitive without validated packaging wall thickness, contents or optical quality.
- Optional `environment.props` are explicit near-field primitives with `id`, `shape`, `sizeM`, `translationM`, `rotationXyzw`, `material` and optional `bevelM`. They support controlled foreground occlusion independently of distant-world alignment.

`scripts/blender_scene.py` imports visual GLB with explicit alignment while preserving the exact product, explicit plinth, near-field props, pinned Blender version and builtin typography. The glTF importer already converts Y-up to Blender Z-up; the adapter does not rotate the imported geometry twice. Actual lighting, source alignment, rendering path and limitations are saved in `render-config.json` and native scene metadata. The official and Gaussian-reconstructed conditions both use this mesh render path. Imported appearance may contain baked lighting; physical material/illumination separation is unverified.

## Offline defaults and Gaussian-to-mesh conversion

The editor supplies an authored Studio plus original Gallery and Botanical room visual-mesh defaults. `scripts/create_default_environments.py` regenerates the GLBs; `examples/worlds/defaults.json` records provenance and hashes. No image, API key or paid generation is required. These environments exclude the exact product and contact plinth. The separate neutral-room GLB/Gaussian PLY fixtures derive from the same original box geometry through `scripts/create_world_fixtures.py`; they are synthetic engineering inputs, not World Labs output or generated-world quality evidence.

`film.splat_mesh.convert_splat(source_path, output_path, *, resolution=96, iso_level=0.5, max_splats=100000, source_up='Y')` creates a self-contained vertex-coloured GLB and `<output>.reconstruction.json`. Gaussian PLY is parsed locally; SPZ uses `scripts/decode_splat.mjs` with pinned Spark 2.3.1 `PackedSplats` decoding in Node, without a browser, WebGL or provider call. The optional numerical stack is pinned in `requirements-worlds.txt`.

The converter samples an opacity-weighted anisotropic Gaussian density field and extracts an isosurface with marching cubes. It does not triangulate point centres. It preserves covariance and opacity approximately, broadens sub-voxel radii for the finite grid and transfers SH0 colours to a rough vertex-coloured material. Bounds include at most 128³ voxels, two million decoded splats, 200,000 selected splats and 200 million estimated voxel contributions. The default uses resolution 96 and at most 100,000 selected splats. Reports record source/output hashes, voxel size, isovalue, radius flooring, deterministic thinning/weights, colour transfer, geometry counts and dependency versions.

Only the declared source-up basis is baked into the reconstructed GLB. Its source-up becomes Y; the imported derived entry retains the original Gaussian world's `scaleToMeters`, `rotationXyzw` and `translationM`. Provenance includes `representation:'gaussian-reconstructed-mesh'`, the source splat hash and reconstruction settings. Official HQ GLB alignment is reviewed separately: the SPZ metric factor is not assumed to describe HQ mesh units.

Reconstruction is experimental. Thin structures, topology, holes and thickness depend on voxel size and isovalue. Rough vertex colours do not reconstruct higher spherical harmonics, view dependence, glass, separated baked lighting or physically correct materials. Local fixture checks do not establish equivalence to an official mesh, generated scene or reference photograph.

## Browser and HTTP contract

`web/` provides the React/TypeScript/Three.js/Vite editor with pinned versions and lockfile, including diagnostic Spark Gaussian rendering. It has a portrait viewport, control rail and three-shot timeline. Playback starts paused. Controls include numeric fields, undo/redo, selection, saves/reopen, a separate approved revision, visible draft labeling and final still/reel requests. Reduced-motion preferences are respected; rendering pauses when hidden/offscreen and is demand-driven while idle. Focus remains in controls across updates.

The local stdlib Python HTTP server `film/server.py` persists project revisions and dispatches render jobs. It binds 127.0.0.1:8787 and serves web/dist and asset files. All mutating fetches include `X-Product-Suite: 1`; Origin and Host are restricted to the matching local server/Vite proxy. JSON errors are `{error:message}` with non-2xx status. Browser never receives secrets or arbitrary server paths. API:

- GET `/api/bootstrap` -> `{project:{id,name,scene,revisionId,approvedRevisionId}, projects:[{id,name,updatedAt,revisionId}], worlds:[{id,name,environment}], capabilities:{worldlabsConfigured,blenderAvailable,ffmpegAvailable}, jobs:[jobSummary]}`. Create default project from fixture if empty.
- POST `/api/evaluate` `{scene}` -> `{scene,frames,digest}` (shared Python sampled transforms). Cache these in UI for immediate deterministic scrubbing/playback. Scene edits debounce evaluation; stale requests cannot replace latest state.
- POST `/api/projects` `{name,scene?}` -> full project. GET `/api/projects/<id>` -> full project.
- PUT `/api/projects/<id>` `{scene,name?,expectedRevisionId}` -> full project. Saves new immutable revision; stale revision gives 409.
- POST `/api/projects/<id>/approve` `{expectedRevisionId}` -> full project. Separate approved pointer.
- GET `/api/projects/<id>/revisions/<revisionId>` -> full project-shaped historical revision.
- POST `/api/renders` `{scene,kind:'still'|'reel',frame:1,width:270,height:480,samples:8}` -> jobSummary. Still defaults 540x960/32spp, reel draft270x480/8spp unless supplied. Background durable local job. Diagnostic splat dispatch captures a plate before product render; the final comparison uses meshes. Exact sourceDigest recorded.
- GET `/api/jobs` -> array summaries. GET `/api/jobs/<id>` -> summary. POST `/api/jobs/<id>/cancel` -> summary. POST `/api/jobs/<id>/resume` -> summary. Summary `{id,kind,state,frame?,sourceDigest,width,height,completedFrames,totalFrames,error?,artifacts:[{name,url}],createdAt}`. UI must label render as stale if digest differs from current evaluated scene.
- GET `/api/jobs/<id>/files/<name>` -> allowlisted artifact bytes (still.png, film.mp4, scene.blend, contact-sheet.png), media MIME. Stills may expose name `still.png` only. No general filesystem route.
- POST `/api/worlds/import?name=...&sourceUp=Y&owner=...&reuseBasis=...` raw file bytes; header `X-Asset-Filename: room.glb` and content-type application/octet-stream; return library entry. GET `/api/worlds` -> entries. GET `/api/assets/<hash>.<ext>` -> immutable asset bytes. Selected entry.environment can replace scene.environment, retaining exact explicit plinth and product placement. Imported worlds unreviewed; UI must show this. Show scale/axis/translation numeric alignment controls.
- GET `/api/worldlabs/status` -> `{configured:bool}` for local server-key availability only. No key input in browser.
- GET `/api/github-worlds/runs` lists experiment runs. POST `/api/github-worlds/generate` dispatches the same-world workflow with a preset, optional prompt/public reference-image URL and credit cap. POST `/api/github-worlds/runs/<id>/import` validates and imports a successful workflow artifact. Local controls use authenticated `gh`; they do not retrieve the encrypted World Labs key.

No provider key is required to use defaults, synthetic fixtures, the editor, local reconstruction or local render jobs. Explicit World Labs generation requires API credits and `WORLDLABS_API_KEY` in the GitHub workflow's `Myenv` environment or a local server process. Never store it in Git/browser/VITE vars. The workflow generates one world, exports the official HQ visual mesh, preserves its 500k SPZ, reconstructs that SPZ locally and prepares fifteen unreviewed probe scenes; it does not render or approve them. Public HTTPS images can guide generation. Private local image references use `scripts/worldlabs_experiment.py --image-path` and are sent to World Labs without committing the image or persisting its inline base64 payload in request logs. Documented cost preflight, saved operation IDs and recovery are described in [worldlabs-api.md](worldlabs-api.md). An uncertain paid submission is not automatically retried as a new generation.

## Diagnostic native Gaussian capture boundary

`scripts/capture_splats.mjs` uses the isolated `/capture` route with `window.productSuiteCapture.load(payload)` -> Promise<void>, and `.frame(frameNumber)` -> Promise<void>. Payload `{scene,frames,width,height,assetUrl}`. No product/plinth in capture; Gaussian world background only. It sets the exact sampled camera each frame, waits for Spark loading and completed sorting/rendering, and draws once. Canvas id `splat-capture`. CLI: `node scripts/capture_splats.mjs --url http://127.0.0.1:8787 --samples /abs/samples.json --output /abs/plate --asset-url /api/assets/hash.spz --width 270 --height 480 [--frames 1,2]`. It uses pinned Playwright; browser binaries are installed separately. No paid/provider calls occur during capture.

Capture writes `plate/000001.png` and `capture-manifest.json` with the scene digest, asset hash, profile, frame membership and PNG hashes. It uses sRGB output and no tone mapping; Blender decodes to linear and applies AgX once after compositing transparent Cycles near-field geometry. Worker and adapter verify matching manifest inputs and exact resolution, rejecting missing or mismatched plates rather than substituting an authored background. Saved native scenes use relative sequence paths and require `plate/` alongside `scene.blend`.

The plate supplies no splat depth, native Cycles world geometry, reflections, refraction, indirect illumination or shadow equivalence. Explicit near-field props can occlude the product; distant plate content cannot. These limitations are recorded in render metadata. This compatibility path is separate from the requested official/reconstructed **mesh** experiment. A real provider comparison still requires API access/credits or supplied exports and reviewed outputs; offline fixtures establish engineering behavior only.
